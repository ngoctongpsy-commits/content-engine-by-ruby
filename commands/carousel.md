Create a carousel for the topic in $ARGUMENTS. Use the **carousel-production** skill: pick the template per
`knowledge/carousel-templates.md` (C technical / B hot-take / A concept-default; never repeat the previous one),
write the 7-slide spec from `templates/carousel-spec.template.json` with brand colors from `config/brand.json`,
render via `scripts/build_carousel.py` to `outputs/carousels/`, then audit the slides and offer to distribute.
